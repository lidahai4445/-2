# 《光电子器件》全考点三刷通关系统

基于《光电子器件重点内容》考纲与 9 页手写扫描笔记构建的本地/在线交互式刷题网页（浅色主题 Light Theme）。

## ✨ 核心功能

1. **全考点三刷递进系统（`0/3` → `1/3` → `2/3` → `3/3 ★`）**
   - **一刷（概念快筛）**：单选辨析，快速扫除概念盲区。
   - **二刷（关键词挖空）**：核心采分词填空自检，强化精准记忆。
   - **三刷（终极通关）**：闭卷默写采分点核对清单 + 现实草稿纸分步实战计算。
2. **自动错题整理本**
   - 任何刷次中答错或自评未掌握的考点自动归集，记录累计错误次数、最近出错时间与原因，支持添加个人防错笔记与打印导出。
3. **现实草稿纸辅助计算工作台**
   - 覆盖 LED/LD 特性与外微分量子效率、单模光纤 $V$ 值与衰减系数 $\alpha$、PIN/APD 截止波长与雪崩增益 $G$、FRA/FBA 泵浦光波长、EDFA 增益与 $\text{dBm}$ 换算、光耦合器四大参数（插入损耗、附加损耗、分光比、方向性）等核心计算题。
   - 支持**分步中间结果单独验算**、**一键随机变参重算**以及右侧**光电科学计算器 & 物理常数速查**。
4. **9 页原版手写笔记高清对照**
   - 每道题均绑定对应手写笔记扫描页码（`P.1` ~ `P.9`），可随时弹窗查看原图与教材特性曲线。

## 🚀 使用方法

- 直接在浏览器中打开 `index.html` 即可开始刷题（所有三刷进度与错题记录自动保存在浏览器本地 `localStorage` 中）。
